# Vault Home

Obsidian vault root — agent memory + personal notes (dual-use).

## Tiers

| Tier | Folder | Use |
|------|--------|-----|
| Ephemeral | [[daily/]] | One file per day (`YYYY-MM-DD.md`) |
| Episodic | [[sessions/]] | Session / learning notes |
| Semantic | [[decisions/]] | ADRs |
| Semantic | [[projects/]] | Project MOCs |

## Today

Open today's daily via Obsidian **Daily notes** hotkey (folder `daily/`).

## Agent vs Obsidian

| Task | Agent | Obsidian |
|------|-------|----------|
| Daily bullet | `append-daily` | Edit in editor |
| Durable note | `/vault-capture` | Template from `Templates/` |
| Recall | `grep-vault` + `_agent/manifest.json` | Search / graph / backlinks |

`_agent/` is agent catalog only — excluded from graph.
