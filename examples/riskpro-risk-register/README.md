# RiskPro — Risk Register (HTML mock)

Static UI recreation of the Risk Register form (Thai + English labels).

## Open locally

```bash
open examples/riskpro-risk-register/index.html
```

Or open `index.html` in a browser (requires network once for Google Fonts — Sarabun).

## Files

| File | Role |
|------|------|
| `index.html` | Layout, form, sidebar, workflow |
| `styles.css` | Design tokens, components, responsive |

No build step. Minimal JS: C×L score update, RCA tab highlight.
